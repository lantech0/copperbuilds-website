## The Rebrand Goal

The current site looks like it was generated by AI. It uses the typical "dark background + electric cyan + purple gradient" palette that every AI-built agency site uses right now. The fonts and layout patterns are recycled from a thousand other agency templates.

We need a complete visual overhaul that looks like it was designed by humans who have a real point of view — not assembled from design system defaults. The new site should feel like it was built by the same kind of craftspeople we are: skilled, grounded, distinctly American, no-nonsense.

**The site should feel 3D and dimensional** — with depth, layered surfaces, perspective, and physical weight. Not flat. Not floaty SaaS cards. Think crafted, architectural, real.

It should be immediately obvious this site is for small businesses in the USA — not a startup, not a tech company, not a generic global agency.

## Technical Requirements

- Pure HTML + CSS + minimal vanilla JS. No React, Vue, or Angular.
- Tailwind CSS via CDN is acceptable.
- Google Fonts only (no paid fonts).
- Mobile-first responsive design.
- All SEO meta tags, Open Graph, Twitter Card, and canonical URLs on every page.
- Schema.org JSON-LD structured data: Organization + WebSite on homepage, Service on services page, Offer on pricing page, ContactPage on contact page.
- Favicon: /brand_assets/lantech-icon-800.png
- OG image: https://lantech.co/brand_assets/lantech-fb-banner-820x312.png
- One H1 per page, H2 for sections, H3 for cards — no skipped heading levels.
- Accessible: focus-visible states on all interactive elements, ARIA labels on icon-only buttons, semantic HTML throughout.
- Inline SVG for icons — generate a custom icon set that fits the visual identity you choose. Do not use generic icon libraries.
- Animate only transform and opacity. No transition-all.
