06 Build Process

How Every Site Gets Built

Every CopperBuilds site follows the same 10-step process. No shortcuts. No step is skipped regardless of package size.

01
First Contact & Intake
Client submits a free quote request. We respond within 24 hours — a real person, not a bot. If needed, we schedule a 30-minute intake call to collect: services offered, location(s), contact info, and target customer. This replaces any long onboarding forms.
All packages 24-hour response
02
Keyword Research (Step 0)
Before any design work, we identify the exact search terms customers use in the client's market. Each page gets one primary keyword ("plumbing services Tampa") and 2–3 secondary keywords. This drives every title tag, H1, and meta description. Skipping this step is why most trade sites rank for nothing — we never skip it.
All packages Produces: _keyword-map.md
03
Design Brief & Photo Sourcing
We identify the right layout archetype for the trade (Urgency/Emergency for HVAC; Premium Credibility for Roofing; etc.) and source real-looking photography from Pexels for every section. No stock placeholder rectangles in the final build. If the client has their own photos, we use those instead.
All packages
04
Build — Mobile-First, Then Desktop
We always design for 375px (mobile) first, then scale to desktop. Every page is semantic HTML with correct heading hierarchy (one H1 per page, logical H2/H3 structure), correct meta tags, canonical tags, OG tags, Twitter Card tags, image alt text on every img, and lazy loading on below-the-fold images.
All packages Screenshots every round
05
Schema Stack — Structured Data
Every page gets JSON-LD structured data in the head. Standard stack: Organization schema on every page, LocalBusiness schema (or trade-specific sub-type like Plumber, HVACBusiness, Electrician) on home + contact pages, BreadcrumbList on all inner pages, FAQPage schema on service pages with Q&A sections. Validated at schema.org with 0 errors.
All packages Validated at validator.schema.org
06
Quality Gate Check
Before showing the client anything, we run through a full checklist: primary keyword in title, H1, meta description, and first 100 words on every page; canonical tags present; robots.txt and sitemap.xml at site root; no 404 links; form submits correctly; no console errors; looks correct at both 1440px and 375px. Minimum 2 screenshot comparison rounds.
All packages
07
Client Review & Revisions
We send a preview link. Client has 48 hours to review and request changes. Revisions are limited to the package scope (Starter: 1 round, Growth: 2 rounds, Pro: 3 rounds). Change requests outside the original scope are quoted separately. We don't ghost clients between revisions — response within 24 hours guaranteed.
Starter: 1 round Growth: 2 rounds Pro: 3 rounds
08
Google Business Profile Setup
Growth and Pro packages include full GBP setup: claim/verify the profile, NAP exact match with website, primary + secondary categories, service area setup, minimum 5 photos (logo, exterior, work samples), services list with descriptions, first GBP post published, review request link generated and added to site. The GBP URL is added to the site's Organization schema sameAs array.
Growth + Pro only
09
Deploy & Analytics Setup
Site goes live on managed static hosting (Hostinger). Google Analytics 4 configured with conversion tracking (form submits, click-to-call). Google Search Console submitted and verified — sitemap submitted. DNS configured for custom domain. Client receives login credentials to their hosting dashboard, GA4, and GSC.
All packages All plans: live in 14 days
10
Handover & Post-Launch Support
Client receives a full handover package: all file downloads, login credentials, a walkthrough of what was built, and guidance on what to do next (request reviews, keep GBP updated, share the site). Pro clients get 30-day post-launch support — any issues or questions answered within 4 hours.
All packages Pro: 30-day support included
07 Quality Standards

What Every Site Must Have

These are non-negotiable. Every site that leaves CopperBuilds passes all of these. No exceptions for budget or timeline.

On-Page SEO — Per Page
  • Primary keyword in title tag, meta description, H1, and first 100 words
  • Title tag 50–60 characters, unique per page
  • Meta description 150–160 characters, unique per page
  • One H1 per page — never two
  • Logical H2/H3 hierarchy, no skipped heading levels
  • Canonical tag on every page
  • Alt text on every img (descriptive, keyword-relevant where natural)
  • OG title, OG description, OG image, OG url on every page
  • Twitter Card meta tags on every page
Schema Markup — JSON-LD
  • Organization schema on every page
  • LocalBusiness or trade sub-type (Plumber, HVACBusiness, etc.) on home + contact
  • BreadcrumbList on every non-home page
  • FAQPage on any page with Q&A section
  • All schema validated at validator.schema.org — 0 errors
Technical SEO — Site Level
  • robots.txt at site root — allows crawl, references sitemap
  • sitemap.xml listing all pages with lastmod dates
  • No noindex on rankable pages
  • No 404 links — all nav and internal links resolve
  • No console errors on load
  • Google Search Console submitted + sitemap submitted
Performance & Mobile
  • Mobile PageSpeed score ≥ 80 (target 90+)
  • LCP under 2.5s, INP under 200ms, CLS under 0.1
  • Images with width + height attributes (prevents layout shift)
  • loading="lazy" on below-the-fold images
  • Hero images under 200KB, inline images under 100KB
  • No render-blocking scripts in head
  • Tested at 375px — no overflow, no broken layouts

Words We NEVER Use
synergy · leverage · ecosystem · holistic · seamless · solutions · deliverables · stakeholders · cutting-edge · state-of-the-art · innovative · empower · transform · revolutionize · best-in-class · world-class

Writing Rules

Do
  • Use contractions freely — "we're", "you'll", "it's", "don't"
  • Lead with the client's problem, not our service feature
  • Use "you" and "your business" — not "clients" or "customers"
  • Short sentences. Then a longer one for rhythm.
  • Explain every technical term or remove it
  • Let prices be visible — transparency is a brand value
  • Name the enemy (overpriced agencies) when relevant
Don't
  • ✗  Start sentences with "We" — focus stays on the client
  • ✗  Stack adjectives — "professional, affordable, fast" means nothing
  • ✗  Use passive voice in CTAs
  • ✗  Write long paragraphs on service pages
  • ✗  Over-explain process — clients care about outcomes
  • ✗  Say "we think" or "we believe" — own your claims
  • ✗  Use jargon without plain-language explanation
