# Prospects — Lantech Website

Each file here is one prospect researched via `/prospect`.

## File naming
`[business-slug]-[YYYY-MM-DD].md`
Example: `mikes-plumbing-2026-05-02.md`

## Required fields (top of every file)
```
**Date researched:** YYYY-MM-DD
**Status:** Hot / Warm / Cold / Dead
**Follow-up date:** YYYY-MM-DD
**Next action:** [e.g. "Send outreach email" / "Follow-up call" / "Book discovery call"]
```

The EA reads `follow_up_date` and `next_action` to surface what needs attention each session.
