## Method correction (2026-07-02): DataForSEO local_pack `domain` field is NOT a reliable website-presence signal

Initially inferred "no website" for Lex and Elmer's Home Services based on their cached SERP `domain` field showing `www.google.com`. This was wrong — user confirmed Lex has a real site (lexairconditioning.com, verified live via curl), and WebSearch confirmed Elmer's does too (elmershomeservices.com). The `domain`/`url` fields in DataForSEO's local_pack data reflect where that SERP entry's link goes (often a Google-hosted redirect), not the business's actual configured GBP "Website" field — these are different things. Corrected method: cross-check via WebSearch for "[business name] Yelp BBB website" — reliably surfaces the real website if one exists. Google Maps itself can't be checked via WebFetch (confirmed empty result, it's a JS-rendered app) — manual browser check or WebSearch directory cross-reference are the only reliable free methods available this session.
