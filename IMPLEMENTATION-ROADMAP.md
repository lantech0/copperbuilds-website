# Implementation Roadmap — Website Development for Small Business (USA)
> Generated: 2026-04-17 | 4-Phase Plan

---

## Phase 1: Foundation (Weeks 1–4)

### Technical Setup
- [ ] Install Google Analytics 4 + Google Search Console
- [ ] Submit XML sitemap to GSC
- [ ] Set up Google Business Profile (if local)
- [ ] Configure canonical URLs and robots.txt
- [ ] Achieve Core Web Vitals: LCP < 2.5s, CLS < 0.1, INP < 200ms
- [ ] Verify mobile-first rendering
- [ ] Set up 301 redirects (if migrating)

### Core Pages (Build + Optimize)
- [ ] Home page — target: "website design for small business"
- [ ] /services/web-design/ — target: "professional website design for small business"
- [ ] /pricing/ — target: "small business website design packages"
- [ ] /about/ + /about/team/ — E-E-A-T foundation
- [ ] /contact/ — lead capture with form
- [ ] /faq/ — FAQ schema targeting cost + process questions

### Schema Implementation
- [ ] Organization schema on Home
- [ ] ProfessionalService schema on Home + Services
- [ ] FAQPage schema on /faq/ and key service pages

### Analytics & Tracking
- [ ] Goal tracking: contact form submissions
- [ ] Goal tracking: phone call clicks
- [ ] Set up GSC keyword tracking dashboard

**Phase 1 Success Criteria:** Site indexed, Core Web Vitals passing, 6 core pages live with schema

## Phase 2: Expansion (Weeks 5–12)

### Content Creation
- [ ] Publish 4 blog posts (see Content Calendar Months 1–2)
- [ ] Build 4 service sub-pages (/ecommerce, /wordpress, /landing-pages, /redesign)
- [ ] Build 5 industry pages (restaurants, plumbers, salons, contractors, law firms)
- [ ] Build 3 case studies for /work/

### SEO Tasks
- [ ] Internal linking audit — ensure all new pages linked from relevant existing pages
- [ ] Add FAQ schema to all service pages
- [ ] Submit updated sitemap after each batch of new pages
- [ ] Build first 10 citations (Google, Yelp, Bing Places, Apple Maps, BBB, etc.)

### E-E-A-T
- [ ] Add team member photos and bios to /about/team/
- [ ] Add Google Reviews embed or testimonial widget
- [ ] Add client logos to homepage (with permission)

**Phase 2 Success Criteria:** 25+ pages indexed, 5–10 keywords ranking Top 20, first organic leads

## Phase 3: Scale (Weeks 13–24)

### Location Pages
- [ ] Build 10 city landing pages (New York, LA, Chicago, Houston, Phoenix, Philadelphia, San Antonio, Dallas, Miami, Atlanta)
- [ ] Add LocalBusiness schema to each location page
- [ ] Interlink location pages from services and blog content

### More Industry Pages
- [ ] Build 5 more industry pages (dentists, real estate, gyms, electricians, retail)

### Blog
- [ ] Publish 6 more blog posts (months 3–5 from content calendar)
- [ ] Add internal links from new posts to service/industry pages

### Link Building
- [ ] Guest post outreach: 2–3 posts on small business or web design blogs
- [ ] Directory submissions: Clutch, DesignRush, Semrush Agency Directory
- [ ] Local citations: 20+ total
- [ ] Resource link outreach for cornerstone posts

### Performance Optimization
- [ ] Compress and lazy-load all images
- [ ] Minify CSS/JS
- [ ] Enable browser caching + CDN if not already set

**Phase 3 Success Criteria:** 50+ pages indexed, 20–40 keywords Top 10, 5–10 organic leads/month

## Phase 4: Authority (Months 7–12)

### Content Authority
- [ ] Publish original research piece (linkable asset)
- [ ] Produce 8+ more blog posts (months 9–12)
- [ ] Update older posts with fresh data and expanded content
- [ ] Add author bio schema to all blog posts

### Advanced Link Building
- [ ] HARO/media outreach for brand mentions
- [ ] Partner with complementary businesses (accountants, marketing agencies) for cross-referrals and links
- [ ] Reach out to clients for testimonials + links from their sites

### AI Search (GEO)
- [ ] Audit whether brand appears in ChatGPT, Perplexity, Google AI Overviews for target keywords
- [ ] Add llms.txt to site root
- [ ] Structure key service pages with answer-first format for AI citation readiness
- [ ] Ensure all stats on site are sourced and citable

### Analytics Review
- [ ] Monthly: check GSC for keyword ranking movement
- [ ] Monthly: check GA4 for organic sessions + goal conversions
- [ ] Quarterly: competitor ranking comparison
- [ ] Quarterly: update content based on what's gaining traction

**Phase 4 Success Criteria:** 80–150 keywords Top 10, DA 30+, 15–30 organic leads/month, brand appearing in AI search results

## Quick Wins (Do First)

These can yield results within 4–8 weeks:

1. **Publish the pricing page** — "small business website design packages" is high-intent with moderate competition
2. **Write the cost guide** — "how much does a website cost for a small business" gets 4,000–7,000 searches/month and is an easy Top 10 target for a new site with long-form content
3. **Submit to Clutch + DesignRush** — free directory listings that appear in branded searches and drive referral traffic fast
4. **Add FAQ schema to home + services** — quick schema win, eligible for Google featured snippets within weeks
5. **Set up Google Business Profile** — free, immediate visibility for local searches
